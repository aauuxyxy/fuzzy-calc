# UI/UX Flow

## 画面遷移
本アプリは単一画面（Single Screen）構成です。
- **Main Screen (電卓画面)**: すべての操作をこの画面で行います。

## 画面レイアウト
1. **ディスプレイエリア (上部)**
   - 以前の入力と演算子を表示するサブディスプレイ（小さめ）
   - 現在の入力値、または「ファジー化された計算結果」を表示するメインディスプレイ（大きめ）
2. **キーパッドエリア (下部)**
   - 数字キー（0-9, .）
   - 演算子キー（+, -, *, /）
   - アクションキー（C [クリア], = [イコール]）

## ユーザー体験 (UX) の流れ
1. **起動**: シンプルで少しゆるい雰囲気のデザインが表示される。
2. **入力**: 通常の電卓と同じように数字と演算子を入力。「100 + 100」など。
3. **計算実行**: 「=」ボタンをタップする。
4. **結果表示**: 一瞬、「200 くらいじゃないですかね、知らんけど」などのファジーなテキストがメインディスプレイにデカデカと表示される。
5. **リセット**: 「C」ボタンを押す、または次の数字を入力し始めると表示がリセットされる。
