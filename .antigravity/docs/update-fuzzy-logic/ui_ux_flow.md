# UI/UX Flow & Components

## 画面構成

### 1. Header (New)
- **位置**: 画面最上部中央
- **コンポーネント**: `Logo`
- **役割**: ブランド認知。
- **デザイン**: 透過PNGロゴを中央に配置。

### 2. Display Area
- **メインテキスト**: `fuzzify` された結果を大きく表示。
- **サブテキスト**: 入力中の式を表示。
- **Secret Display (New)**: 
    - **位置**: 右下または左下の隅。
    - **フォントサイズ**: 極小（10px程度）。
    - **色**: 背景色に近いグレー（例: `#374151`）。
    - **UX**: ユーザーが「あれ？」と思った時に、よく見ると正解がわかる。

## ユーザーフロー
1. **入力**: ユーザーが数字キーを叩く。
2. **計算**: ユーザーが `=` を叩く。
3. **驚き**: 2桁以上の場合、変な文章や曖昧な数字が出る（「だいたい100万円くらい」など）。
4. **発見**: 画面の隅をよく見ると、本当の数字が小さく書いてあることに気づく。
