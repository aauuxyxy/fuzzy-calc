# Fuzzy Calc

笑える適当電卓アプリ。「だいたいこれくらい」と適当な回答をするReact Native製電卓アプリです。

## 画面確認方法 (開発サーバーの起動)

本プロジェクトは **Expo** を使用して構築されています。画面（UI）や動作を確認するには以下の手順を実行してください。

### 1. 依存パッケージのインストール
初回のみ、プロジェクトルート（`fuzzy-calc`ディレクトリ）でパッケージをインストールします。
```bash
npm install
```

### 2. 開発サーバーの起動
以下のコマンドを実行して Expo の開発サーバーを立ち上げます。
```bash
npx expo start
```
コマンド実行後、ターミナル上に **QRコード** と各種メニューが表示されます。

### 3. 実機やシミュレータでの確認
- **実機 (iOS/Android) で確認する場合**:
  スマートフォンに「Expo Go」アプリをインストールし、カメラ（またはExpo Goアプリ内）からターミナルに表示されたQRコードを読み取ります。
- **iOSシミュレータで確認する場合**:
  Mac環境でXcodeがセットアップされている場合、ターミナルで `i` キーを押すとシミュレータが起動します。
- **Androidエミュレータで確認する場合**:
  Android Studioの仮想デバイスが起動している状態で、ターミナルで `a` キーを押すとエミュレータ上でアプリが開きます。
- **Webブラウザで確認する場合**:
  ターミナルで `w` キーを押すと、Webブラウザ上でアプリが表示されます（※Web向けの動作保証がない機能には注意が必要です）。

## 開発ルール
- ソースコードは `src/` 配下に格納します。
- 変更後は `npm run lint` および `npm run format` で体裁を整えてください。
